# MediConnect

Plateforme de téléconsultation médicale avec triage selon l'urgence (projet Django 5.2).

Cette branche `gestion-medecins` contient l'espace médecin : inscription, file d'attente, consultations, visio, compte rendu (PDF, e-mail, WhatsApp) et gestion des médecins dans le back-office.

Les autres branches de travail :

- `gestion-patient` : module patient (inscription, symptômes, triage, tableau de bord, back-office)
- `preprod` : version de pré-production
